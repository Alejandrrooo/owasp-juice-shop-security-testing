# System context
## What is OWASP Juice Shop?

It is a modern, open-source and intentionally insecure e-commerce web application, designed for cybersecurity training and for validating testing tools and processes.

It simulates a complete e-commerce system that includes user registration and login, product visualization, cart management, checkout process, payments, and user/admin role management. It allows interaction and data validation through the User Interface (UI), API, and database.

## What type of business does it simulate?

It simulates a B2C (Business to Consumer) business focused on selling products to final customers. Users can navigate through the page, search for products, create an account, add products to the cart, complete purchases, and validate previous orders. As an administrator, it is possible to add new products, verify and validate users, orders, and payments, as well as manage the platform.

## What actions generate value?

Browse and search products with detailed information
Register users with authentication
Log in securely
Purchase products through checkout
Manage users/purchases/orders

## What would happen if this system fails in a real environment?

Economic loss
Reputation decreases
In case of user data loss, there is a possibility of legal action
